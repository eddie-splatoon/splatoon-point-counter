# salmon-result

サーモンランの最新のリザルトを、iPhone ミラーリングに映した NSO アプリ（イカリング3）から読み取って記録するスクリプトです。
コントロールパネルの「サーモンラン」タブの「📸 イカリング3から最新のリザルトを取り込む」を押すと動きます。

- イカリング3の API は直接呼びません。公式アプリの画面をタップ・スクロールして、映っている文字を読むだけです
- 文字の読み取りは macOS の Vision、支給ブキはアイコンを参照画像（Leanny/splat3）と照合します
- 画面を操作するので、Docker ではなく **Mac 上でネイティブに実行** してください（macOS 15 以降の iPhone ミラーリングが必要）

## 流れ

1. ボタンを押すと `/api/salmon/import` に依頼が入り、このスクリプトが 1 秒以内に拾います
2. イカリング3で ホーム → サーモンラン のタブを押してバイトヒストリーを読み込み直し、いちばん上（最新）のバイトを開きます
3. 詳細画面を撮影して `data/salmon-results/` に保存し、自分の金イクラ・オオモノ・デス（被救助数）・クリア / 失敗した WAVE・ステージ・日時・支給ブキを読み取ります
4. 結果を送ると、サーバーが今のセッションに記録します。テロップで「リザルトを記録しました」と出ます
5. 最新のバイトが記録済みなら、イカリング3にまだ反映されていないので、15 秒ごとに読み直します（最大 4 分）

クリック・スクロールのたびに、マウスカーソルの位置と前面のアプリを元に戻します（一瞬だけミラーリングが前面になります）。
読み取れない項目があれば、推測で記録せずに失敗にします（支給ブキだけは、照合できなければ記録しません）。読み間違えたときは、コントロールパネルの戦績から削除してください。削除したバイトは取り込み直せます。

## 準備

1. Next.js アプリを起動する（`pnpm dev` または `docker-compose up`）
2. iPhone ミラーリングを開き、NSO アプリでイカリング3の「サーモンラン」タブを表示しておく（ミラーリングのウインドウは最小化しない。ほかのウインドウに隠れていても動きます）
3. ターミナル（このスクリプトを起動するアプリ）に、システム設定 → プライバシーとセキュリティで次の権限を与える
   - **アクセシビリティ**（クリック・スクロールのため）
   - **画面収録**（ミラーリングを撮影するため）
4. リポジトリのルートで起動する（`Ctrl+C` で終了）

   ```bash
   pnpm salmon-result
   ```

初回は venv の作成と依存のインストール、ブキの参照画像のダウンロード（`data/salmon-weapon-refs/`）を行います。

ミラーリングの接続が一時停止していたら、「再開」を押してつなぎ直します。

## 読み取りの確認・調整

保存したキャプチャを読み取って、結果を表示できます（記録はしません）。

```bash
pnpm salmon-result --read data/salmon-results/20261110-210503-detail.png
```

イカリング3の見た目が変わって読めなくなったら、`salmon_result.py` の次の箇所を直します。

- `SelfRowCells`: 自分の行の金イクラ・被救助数の位置と、支給ブキのアイコンを探す範囲（「オオモノシャケ」の文字を基準にした相対位置）
- `open_latest_job`: 画面の移動の手順
- `KNOWN_STAGES`: ステージ名の読み間違いを直すための既知のステージ

## 環境変数

| 変数 | 既定値 | 内容 |
|---|---|---|
| `SALMON_API_BASE` | `http://localhost:3000/` | Next.js アプリの URL |
| `SALMON_CAPTURE_DIR` | `data/salmon-results` | キャプチャの保存先 |
| `SALMON_WEAPON_REFS_DIR` | `data/salmon-weapon-refs` | ブキの参照画像のキャッシュ |

## テスト

`fixtures/` に実際の詳細画面（クリア・失敗・オカシラあり）を置いています。画面を追加するときは、プレイヤー名を塗りつぶしてください。

```bash
cd tools/salmon-result
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/python -m pytest
```
